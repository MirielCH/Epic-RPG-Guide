# Epic RPG Guide Privacy Policy

This policy is effective as of 23 October 2021 and was last updated on 02 November 2026.  

## User information the bot collects

Epic RPG Guide uses user IDs to store your settings. All user IDs are hashed they are stored in the database.  

## Message content access

Epic RPG Guide has access to the content of messages. This access is only used for calculator commands and stats check commands to read the necessary data from EPIC RPG. This data does not get stored and is immediately discarded.

This policy therefore only applies to:

• The bot instance with the user ID 770199669141536768, hosted by myself. If you encounter another Epic RPG Guide with another user ID, it is outside of the scope of this privacy policy, even if it falsely links to this document.  

The bot may also link to external sites that are not operated by me. The same limits apply to those sites.
